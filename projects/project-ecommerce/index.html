System Design & Stack

FULL-STACK ARCHITECTURE

Frontend — Stock_Inventory/

React 19 + Vite

Single-page React application serving both the public B2C shopping storefront and the role-protected Admin ERP portal.

  • UI & Visualization: Tailwind CSS monochrome editorial design system with custom SVG dual-axis spline charts (SmoothSalesTrendChart) and SweetAlert2 dialogs.
  • State & Routing: React Context API (AuthContext, CartContext, WishlistContext) with protected Admin & Customer route guards.
  • API Layer: Modular Axios clients with automatic JWT bearer token interceptors across products, orders, purchase orders, wholesale, and reports.

Backend — Stock_Inventory_Spring/

Spring Boot 3

Layered REST API backend engineered in Java 17/21 with clean separation across controllers, services, DTOs, mappers, entities, and JPA specifications.

  • Security & Auth: Spring Security 6 with stateless JWT filter, BCrypt password hashing, and granular RBAC (ROLE_ADMIN, ROLE_STOCK, ROLE_USER).
  • Persistence & Filtering: PostgreSQL 14+ with Spring Data JPA / Hibernate, dynamic JPA Specifications for multi-criteria product & order search, and automated DataSeeder.
  • Integrations & QA: Cloudinary image hosting, @Async Gmail SMTP HTML email alerts, and JUnit 5 + Mockito + MockMvc integration tests.

Engineering Deep-Dive

CORE MODULES & HIGHLIGHTS

01 Inventory Accounting

FIFO Batch Depletion & COGS Engine

  • Audited stock_batches table storing purchase date, unit cost, received quantity, and remaining quantity.
  • Automatic oldest-first batch consumption during both B2C retail and B2B wholesale checkouts.
  • Preserves EXHAUSTED batch records permanently for exact historical COGS and gross margin accuracy.
  • Below-cost price protection validates retail sales and wholesale contracts against batch unit cost.
02 B2C Retail Experience

Customer Storefront & Checkout Flow

  • Interactive garment hero rail with transparent product cutouts and debounced server-side paginated catalog filtering.
  • Live stock telemetry badges (In Stock, ONLY X LEFT, COMING SOON).
  • 10% VAT tax & shipping calculator ($0 on orders ≥ $100, $5 flat rate below), plus printable A4 tax receipts.
  • Animated scooter order tracker (PENDING → PROCESSING → SHIPPED → DELIVERED) and 2-hour self-cancellation with automatic stock restoration.
03 Operations & B2B

Admin ERP & B2B Wholesale Portal

  • 6 live KPI cards + dual-axis interactive SVG charts comparing settled revenue, COGS depletion, and order volume.
  • Supplier & Purchase Order pipeline (DRAFT → ORDERED → RECEIVED) that automatically spawns new FIFO stock batches on receipt.
  • Dedicated B2B wholesale buyer management with custom pricing, credit limits, and contract fulfillment.
  • Financial reports (/admin/reports) with Gross/Net revenue, COGS, top sellers, and UTF-8 BOM Excel CSV export.
04 Security & Verification

RBAC, Async Email & Automated Testing

  • Terminal order locking prevents edits to completed or cancelled orders after fulfillment milestones.
  • @Async Gmail SMTP service sends HTML receipts, cancellation notices, and admin refund alerts without blocking HTTP responses.
  • Role administration supports ROLE_ADMIN, ROLE_STOCK, and ROLE_USER plus instant account deactivation.
  • Automated JUnit 5, Mockito, and MockMvc integration tests covering Cart, FIFO batch logic, Reports, and Wholesale workflows.
